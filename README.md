# klaud81.github.io

GitHub Pages(Jekyll, minima 테마) 블로그입니다. https://klaud81.github.io

## 글 발행 흐름

1. [youtube-summarizer](https://github.com/klaud81/youtube-summarizer)가 `post/<slug>` 브랜치에 `_posts/YYYY-MM-DD-<slug>.md`를 커밋하고 PR을 엽니다 (초안).
2. PR에서 내용을 검토·수정합니다.
3. PR을 Merge하면 `main`에 반영되어 GitHub Pages가 자동으로 빌드·공개합니다.
